# Community

XDC Network is built by a global community of developers, validators, and users. This page collects the official entry points for getting involved.

---

## Get Involved

- **[Join the Community](https://xinfin.org/join-community)** — the official hub for community membership and contact.
- **[XDC Official Website](https://xinfin.org/)** — news, announcements, and network information.
- **[GitHub (XinFinOrg)](https://github.com/XinFinOrg)** — all core repositories; report bugs, request features, and submit pull requests.

### Chat & Discussion

| Channel | Link | Best For |
|---|---|---|
| Discord | [discord.gg/xdc](https://discord.gg/xdc) | Quick questions, developer support |
| Developer Forum | [www.xdc.dev](https://www.xdc.dev) | Detailed discussions, tutorials, showcases |
| Telegram | [t.me/xinfintalk](https://t.me/xinfintalk) | General community chat |

## Contributing to These Docs

This documentation site is community-maintained and open source. Spot an error, a gap, or an outdated page?

1. Click **Edit this page** at the bottom of any docs page, or
2. Open the repository directly: **[github.com/OpenScanAI/XDCDocs](https://github.com/OpenScanAI/XDCDocs)**
3. Submit a pull request with your changes.

Other ways to contribute to the ecosystem:

- **Code:** Submit PRs to [XinFinOrg repositories](https://github.com/XinFinOrg)
- **Community:** Answer questions on Discord and the forum
- **Testing:** Run testnet nodes and report bugs via [GitHub Issues](https://github.com/XinFinOrg/XDPoSChain/issues)
